 Campus Creators Club Website

 Project Description
Campus Creators Club is a simple university club website created using HTML, CSS, and JavaScript. It helps students explore club activities, view upcoming events, and register for events.

 Website Pages

 1. Home Page
The Home page introduces the club, displays a featured event, and provides information about joining the club.

 2. Events Page
The Events page displays upcoming club events, their dates, locations, and registration links.

3. Registration Page
The Registration page allows students to enter their information and select an event. It also displays saved registrations and provides an option to clear them.

 Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

Features
- Three connected web pages
- Responsive layout for smaller screens
- Event information
- Registration form with validation
- Saved registrations using Local Storage
- Clear all registrations button
- Semantic HTML elements

How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in a browser or use the Live Server extension.
4. Use the navigation menu to visit the Home, Events, and Register pages.
